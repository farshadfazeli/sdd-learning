SECTION 04 · COMPARISON

SDD در برابر Markdown و Prompt

SDD فقط نوشتن چند فایل Markdown نیست؛ رابطهٔ آن فایل‌ها با تصمیم، کد و تست مهم است.

تفاوت اصلی

Prompt تنها

یک درخواست لحظه‌ای است و ممکن است معیار پذیرش و مسیر تغییر را ثبت نکند.

SDD

یک workflow قابل تکرار است که نیازمندی، specification، design، task و تست را متصل می‌کند.

فایل‌های مهم

فایلکاربرد
AGENTS.mdقواعد و زمینهٔ Agent
requirements.mdنیازمندی و معیار پذیرش
design.md / tasks.mdطراحی اجرایی و کارهای قابل انجام

ارزش SDD در ساختارمند کردن فعالیت‌ها و کاهش ریسک workflow است، نه در ادعای ناتوانی Codex بدون آن.
